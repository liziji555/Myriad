苦乐在哪台机器上跑？

本机

服务和任务都在这台电脑上，关掉窗口就停下。Bot 读写你选的一个文件夹。

服务器

连你自己的云服务器或 VPS 上常驻的苦乐，关掉电脑任务也不断。要先能用 SSH 密钥登录。

通过 SSH 连服务器上的苦乐，第一次可能要十几秒。

苦乐没能启动


        

          
          
        

        
常见原因

        
    
          
  • 已经开着一个苦乐（包括终端里的 sa serve、sa chat）：关掉它再打开。
    • 
          
  • config.toml 写错了：按上面的提示改好再打开。
    • 
          
  • 选的工作目录打不开：在菜单「文件 → 更换工作目录」里重新选。
    • 
        

        
    
          
  • 先在终端里 ssh  试试，要能不输密码就登录（用密钥）。
    • 
          
  • 服务器上要有 sa，并且在 PATH 里（比如 ~/.local/bin）。
    • 
          
  • 服务器上的苦乐要开着：在服务器上运行 sa service install --workdir 项目目录，它就会常驻。
    •
