常见原因

        
    
          
  • 已经开着一个 Myriad（包括终端里的 sa serve、sa chat）：关掉它再打开。
    • 
          
  • config.toml 写错了：按上面的提示改好再打开。
    • 
          
  • 选的工作目录打不开：点「连别的服务器」，在本机那一栏「换文件夹」。
    • 
        

        
    
          
  • 先在终端里 ssh  试试，要能不输密码就登录（用密钥）。
    • 
          
  • 服务器上要有 sa，并且在 PATH 里（比如 ~/.local/bin）。
    • 
          
  • 服务器上的 Myriad 要开着：在服务器上运行 sa service install --workdir 项目目录，它就会常驻。
