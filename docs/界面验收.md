## 界面的摆法

界面是「左侧栏 + 现场栏 + 主线 + 面板」：

- **现场栏**（顶上一条）：每个 Bot 一块牌子，头像加一句它此刻在做什么。有事等你时牌子变成橙色，点一下跳到主线上对应的那条。
- **主线**（中间）：你说的话、Bot 的回复、它做的每一步、任务、外面来的事，按时间挂在同一条线上。开任务、做的过程、交结果挨在一起时，节点之间那段线加重，看得出谁引出了谁。
- **左侧栏**：房间（有 Bot 在忙或等你时带一个小点）、队员此刻的状态、任务和用量这些页的入口。可以收成图标窄条；窗口窄时变成从左上角呼出的抽屉。
- **面板**：执行、任务、成员、用量、审计这些页，从左侧栏或右上角「面板」打开，不用时收着。「执行」页按 Bot 分卡片，显示状态、耗时、模型档位、步骤进度和最近几步，和现场栏、主线上的状态一致；几个 Bot 同时在说时各自一张在动的卡，在房间里说话或排队的卡上有只停它自己的「停止」。
- **待发队列**：Bot 在说时回车，话排在输入框上方「待发 N 句」里，不进主线；可以改字（回车保存、Esc 不改）、往前往后挪、取消。Bot 都说完了排在最前面的一句进主线，下一句等再次说完。点「停止」队列不清掉。队列不空时回车也是排到最后。「插话」按钮只在有 Bot 在说时出现，点了马上发。刷新、重启服务后队列还在。
- **讨论方式**：面板「成员」页最上面「没点名的话」可选普通、并行回复、轮流讨论、独立评议，下面一行说明这种方式怎么接；选轮流讨论时旁边多一个「转几圈」（1 到 3）。改了马上生效，刷新、别的标签页里也一样。普通：没点名只有一个 Bot 回答。并行回复：每个 Bot 各一条回复，同时开始。轮流讨论：按成员顺序一条接一条，转完设的圈数。独立评议：每个 Bot 各一条，后说的回复里没有引用前面的答案。点了名的话在哪种方式下都只有被点到的回答。
- **协作视图**：主线上方「对话 / 协作」两个页签。「协作」里你、主 Agent（房间的入口 Bot）和每个成员各一条竖线，往下一个节点就是做完一步：空心圈是接下一件事，圆点是一步，菱形是交给别人，方块是任务，大圆是说完了。派活、成员之间交接（线中间一颗菱形）、交回结果（虚线）走两行之间的横轨道，颜色从一方渐变到另一方；接手的还在做时线上有光在流动，那条竖线后面有一条淡色带；刚发生的传递（20 秒内）飞一道光过去，刷新不重放。你每说一句话另起一轮。鼠标停在节点或竖线顶上的牌子上，只亮和它相连的；点节点回到对话里那条消息。主线上 `ask_bot` 那句话仍标「交给 某某」，不再画弯线。系统打开「减少动态效果」时只留静止的线。
- **左右分开**：你说的话靠右，Bot 和外面（GitHub、Telegram）来的消息靠左。Bot 回复中途你发的话标着「插话」，下面写一句它没有停下；几个 Bot 同时在说时，没点名的插话算给所有在说的，点了名的只算给被点到的。你说的每句话旁边标着「回复中」「已回复」「已停止」或「回复失败」：算接这句话的，是它之后、你下一句之前开始的 Bot 回复（含它们交接出去的），插话还算给它插进去的那条；接的 Bot 里有一个出错或写到一半服务退出就是「回复失败」；没有 Bot 接的不标。

上面清单里的「左栏」「右栏」是方案里的叫法，对应现在的左侧栏和面板。

## 这一轮补上的东西各在哪

- 面板开没开、多宽，左侧栏收没收：`web/src/api/layout.ts`；插话怎么认出来：`web/src/api/steer.ts`；回复标记：`web/src/api/replies.ts`；待发队列：`web/src/components/QueueList.tsx`、`crates/sa-engine/src/queue.rs`；明暗：`web/src/api/theme.ts`。都记在浏览器的 `localStorage` 里。
- 草稿：`web/src/api/drafts.ts`，一个房间一份，发出去之后清掉。
- `/` 命令：`web/src/api/slash.ts`，命令就是命令面板里的那些动作。
- 步骤的结果：服务端每一步最多留 2000 个字，一条回复里所有步骤加起来最多留 4 万字（超了从最早的步骤开始不留）；完整的在数据目录的 `sessions/*.jsonl` 里。
