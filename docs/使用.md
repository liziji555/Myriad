# 使用

一页纸的上手说明。每一项的细节在 README 对应的小节里。

## 房间和 Bot

- 顶上的现场栏写着每个 Bot 此刻在做什么，有事等你时变成橙色，点一下跳过去；中间是一条主线，对话、Bot 做的每一步、任务都按时间排在上面。
- 左侧栏放房间、队员和任务、用量这些页的入口，点左上角的按钮收成一条只有图标的窄条（窗口窄于 1100 像素时，左侧栏变成点「苦乐 / 房间名」呼出的抽屉）。点右上角「面板」也能打开这些页。
- 你说的话靠右，Bot 和外面来的消息靠左。Bot 正在回复时你照样能发：这是「插话」，它不会停下，下一次想之前会看到；`@` 别的 Bot 则会先打断再交接。
- 一个房间里最多 6 个 Bot，各写各的分工。`@名字` 点名谁就谁答；不点名时按分工挑一个，挑不出来交给入口 Bot。
- 在面板的「成员」页新建、修改 Bot，把 Bot 拉进或请出房间，换入口。同一页最下面可以把这个房间的团队导出成模板文件，或者导入一份模板。

## 对话

- 回车发送，Shift+回车换行。输入 `@` 点名一个 Bot，输入 `/` 找命令（打开某个面板、新建房间、停止回复）。
- 写了一半没发的话按房间记着，换房间、刷新都还在。
- Bot 回复下面的「N 步操作」点开能看到它每一步做了什么、拿到了什么结果。
- 「停止」会停下正在写的回复，连同它启动的命令。

## 审批

- 工作目录里面写文件直接做。执行命令、往工作目录外面写、推送分支、开 PR、调用 MCP 工具会先弹审批卡：允许一次、总是允许、拒绝。任务里的命令多一个「这个任务里的命令都允许」，选了之后这个任务再执行命令不问（推送、用 `gh` 的照样问）。
- 10 分钟不处理按拒绝算。
- 没有系统级的沙箱：命令一旦批准，就以你的身份运行。

## 任务

- 要花些功夫的事，Bot 会开成任务，在独立的目录里做，做完交结果等你验收。验收通过，改动才回到你的工作目录。
- 面板的「任务」页里可以回答它的问题、打回重做、停止、取消。

## 花了多少、谁做了什么

- 面板的「用量」页：今天和最近 7 天，按模型、Bot、任务分。到每日上限后模型调用会被拦下。
- 面板的「审计」页：每一次审批、Bot 执行的命令和改的文件、任务的每一步、设置的改动。命令行里是 `sa audit`。

## 定时、外面的连接、技能

- 「定时」页：到点让一个 Bot 做一件事，没话说时它不出声。只有 `sa serve` 开着才会做。
- 「连接」页：把 GitHub 仓库的事件、Telegram 聊天接进房间。
- 「扩展」页：数据目录 `skills/` 里的技能和 `config.toml` 里配的 MCP 服务。

## 键盘

- `Ctrl K`（Mac 上 `⌘ K`）：命令面板，搜房间、Bot、任务和动作。
- 面板左边那条线可以拖宽，也可以聚焦后用左右方向键调。
- 右上角的明暗按钮在「跟随系统 / 浅色 / 深色」之间切。

怎么检验这套东西合不合用，见《[用六个信号检验](验收.md)》；界面逐条的情况见《[界面验收 20 条](界面验收.md)》。
